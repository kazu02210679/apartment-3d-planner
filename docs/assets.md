# アセットとライセンス

現在の家具・機器・照明・ポート・ケーブルは、Three.js の手続き的なジオメトリとマテリアルで描画します。外部画像、外部モデル、CDN フォント、実行時のアセット取得は使用しません。見た目は説明用であり、実在製品の寸法精度、規格適合、施工可否を保証するものではありません。

将来、外部アセットを追加する場合は、リポジトリへ同梱する前に出所、作者、ライセンス、改変の有無、必要な通知、ファイル名をこの文書に記録します。利用条件が再配布を許可しないアセットは同梱しません。

実行時依存関係の完全な非開発依存閉包は [第三者ソフトウェア通知](../THIRD_PARTY_NOTICES.md) に生成します。各項目には npm の名前・バージョン、宣言ライセンス、同梱された LICENSE/COPYING/NOTICE 本文を記録します。実行時依存関係を更新したら `npm run notices:generate` を実行し、差分を確認してコミットしてください。`npm run notices:check` は通知の古さまたはライセンス証跡の欠落を失敗にします。
