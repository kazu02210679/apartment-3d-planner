# カタログ拡張ガイド

新しい品目は `src/catalog` の定義として追加します。`catalogId`、リビジョン、既定寸法、寸法範囲、表示名、プリセット、ローカルポートを明示し、既に公開した ID やポート ID を再利用・改名しないでください。

## 寸法と原点

寸法は mm で定義します。モデルはエンティティの中心原点と解決済みの幅・高さ・奥行きの境界内に収めます。プリセットとカスタム寸法はいずれも解決済み寸法を使い、固定寸法のアクセントを別の座標系に置かないでください。

デスク、棚、照明、機器などの詳細モデルは、既存の `catalogId` を変えずにレンダリング分岐を追加します。選択枠、ロック、非表示、範囲外、プレビューのガードも単純な箱モデルと同じように維持します。

## ポートとケーブル

ポートは親エンティティ局所座標の `position` と `direction` を持ちます。ケーブルは `cable.generic` と固定の `end-a`／`end-b` を使います。新規接続はケーブル端と互換な非ケーブルポートの 1 対だけを作成し、配線は `properties.routing` に保存します。

カタログのケーブル寸法を変更する経路では、端点アンカーを解決済みの境界へ決定的に再調整します。自由端の明示位置は範囲内なら保持し、範囲外なら同じ比率で収めます。

## 検証

追加時にはカタログ解決、境界、インポート、書き出し、Undo／自動保存、R3F 表示をテストします。ポート付き品目は親の回転後のワールド座標、レガシー接続の読み取り専用表示、プレビュー時の編集ハンドル非表示も確認してください。`productUrl` のような文字列は説明用データであり、アプリが取得する URL にしてはいけません。
