# アーキテクチャ

Apartment 3D Planner は React、Three.js、React Three Fiber によるブラウザ完結型アプリです。サーバー API や認証はなく、編集状態は Local Storage と JSON ファイルで扱います。

## 状態とコマンド

`EditorStore` は UI が読むファサードです。内部の `CommandStore` は不変なシーンスナップショット、選択、履歴、保存状態、編集ドラフトを管理します。ユーザー操作はコマンドとして実行され、成功した操作ごとに 1 回だけ Undo と自動保存を記録します。ドラッグや数値入力はトランザクションとして開始・更新・確定または取消します。

シーンは正規化済み JSON を唯一の共有形式とし、安定 ID をキーにします。インポートは検証と移行を完了してから状態を置き換えるため、失敗した入力は既存の最後に有効な状態を壊しません。

## 3D 表示

`SceneCanvas` は `React.lazy` で遅延読み込みされます。読み込み中と WebGL／レンダラー失敗時には、外側の境界がアクセス可能な代替表示を提供します。`SceneRoot` は正規化されたシーンを R3F のエンティティ、ポート、ケーブル、選択表示へ写像します。

ドメイン上の長さはすべて mm、回転は度です。レンダラー境界だけが Three.js の表示単位へ変換します。カタログ寸法・ポート位置・経由点をレンダラー内で別形式に永続化してはいけません。

編集モードでは選択、変形、サイズ変更、ケーブルのポート／経由点ハンドルを表示します。プレビューモードは同じシーン JSON を使い、編集用ハンドルを表示しません。非表示・ロック・範囲外の状態は読み取り専用の視覚表現に反映します。

## 永続化境界

起動時は Local Storage の JSON を読み、必要なら v0 形式を v1 へ移行します。書き出しは正規化された v1 JSON、読み込みは全体検証後の原子的な置換です。外部 URL、WebSocket、テレメトリーは実行時に使用しません。
